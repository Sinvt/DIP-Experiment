# 🎓 数字图像处理课程实验 (Digital Image Processing)

本仓库包含了 **2024/2025年数字图像处理（DIP）** 课程的全部四次上机实验。整个项目不仅涵盖了传统数字图像处理（信号变换、滤波去噪、传统分割等）的经典算法实现，还深度融合了现代计算机视觉中的**深度学习模型**（DnCNN、CNN、Mask R-CNN），并对模型在不同噪声环境下的鲁棒性进行了全面评测。

---

## 📂 实验大纲与内容导航

### 🌟 实验一：图像变换实验 (Exp1)
**目标**：理解图像频域特性，掌握传统与基于深度学习的图像压缩技术。
- **传统变换**：实现了二维傅里叶变换（FFT）、离散余弦变换（DCT）和哈达玛变换（Hadamard），并对其系数矩阵的频谱进行可视化与截断重建分析。
- **深度学习压缩**：基于预训练的 `bmshj2018_factorized` 模型（CompressAI 框架）实现了端到端的深度学习图像压缩与重建，并与传统变换编码的峰值信噪比（PSNR）进行了客观对比。

### 🌟 实验二：图像增强复原实验 (Exp2)
**目标**：掌握空间滤波去噪算法，探索深度神经网络在图像复原中的强大能力。
- **传统去噪**：针对高斯噪声与椒盐噪声，分别实现了空间均值滤波与中值滤波，并探究了不同窗口/掩码尺寸对去噪效果（PSNR）的影响。
- **深度学习去噪**：部署并使用了 `DnCNN`（深度卷积去噪神经网络）预训练模型，成功对高斯噪声污染图进行了高质量的增强复原。

### 🌟 实验三：CIFAR-10 物体识别 (Exp3)
**目标**：掌握分类与识别问题的实质，熟练应用机器学习/深度学习进行图像分类。
- **深度学习分类**：基于 PyTorch 搭建了卷积神经网络（CNN），在 CIFAR-10 数据集上完成了完整的训练与测试流，识别准确率均达到 60% 以上。
- **鲁棒性测试**：在测试图像中人为添加强度为 0.1 的椒盐噪声，再次进行推理验证，并使用 Tensorboard / Matplotlib 绘制了详尽的 Loss 曲线与精确度统计图表。

### 🌟 实验四：图像分割处理实验 (Exp4)
**目标**：结合传统数学形态学与前沿深度学习方案，实现全场景的图像分割。
- **传统分割方案**：使用大津法（Otsu 类间方差阈值算法）实现了灰度图像的二值化分割，并结合数学形态学（不同半径 r 的腐蚀与膨胀）去除了细小残余误分割点。
- **深度学习实例分割 (Mask R-CNN)**：
  - 成功调度并运行了 PyTorch 官方的 `MaskRCNN_ResNet50_FPN_V2` 预训练模型，对 COCO 2017 验证集进行了大规模实例分割，完美提取了高精度的彩色掩码。
  - **加分项**：对模型进行了冻结与微调（Fine-Tuning）训练，显著提升了目标检测与分割的综合得分（Mask-AP）。
  - **现场测评防作弊扩展**：编写了全自动的抗干扰评估脚本（加注不同等级的高斯噪声），并输出了一键生成“算法准确度 vs 噪声强度”衰减关系图的学术级流程。

## 🛠️ 环境配置与避坑指南

本仓库代码主要依赖于 Python 与 PyTorch 生态。

*   **基础核心环境**：`conda` + `pytorch` + `torchvision` + `opencv-python` + `pycocotools`。
*   **硬件加速**：代码默认进行了设备自适应，若本地环境支持 CUDA（如实验四中对 RTX 5070 (sm_120) 架构的完美适配），将自动激活 GPU 加速。
*   **Docker 部署经验**：如果需要在 WSL2 或 Linux 服务器上通过 Docker 配置老旧架构或复杂环境，请强烈建议查阅 [Exp4/Docker_Detectron2_部署避坑指南.md](./Exp4/Docker_Detectron2_部署避坑指南.md)，里面详细记录了关于挂载路径、纯英文目录规范及打包镜像文件的“血泪排雷”经验。
